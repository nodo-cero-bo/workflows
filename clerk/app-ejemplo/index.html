Iniciá sesión y pedile tu perfil a n8n

Clerk resuelve el login. La página le pide a Clerk un token de sesión y lo manda a tu webhook de n8n, que lo verifica y busca tu fila en Supabase.

esta página Clerk n8n · /mi-perfil Supabase

Falta completar dos datos

Abrí index.html y, arriba de todo en el script, completá PUBLISHABLE_KEY (la Publishable key de Clerk, empieza con pk_) y URL_MI_PERFIL (la Production URL del webhook del workflow 21). El README de esta carpeta explica dónde está cada una.

1. Iniciá sesión

Se abre la ventana de Clerk. Si todavía no tenés cuenta en tu aplicación, creala desde ahí.

2. Llamá a tu API de n8n

La página pide el token con Clerk.session.getToken() y lo manda en el encabezado Authorization: Bearer <token>.

Qué dice tu token

    
Los datos del token de sesión, decodificados (no hace falta ninguna clave para leerlos; para confiar en ellos, n8n verifica la firma). Vence en un minuto: Clerk lo renueva por su cuenta cada vez que llamás a getToken().
